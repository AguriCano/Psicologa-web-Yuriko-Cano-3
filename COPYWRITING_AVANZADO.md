# 📝 COPYWRITING AVANZADO - Microcopy y Estrategia de Textos

## Introducción

El **copywriting en terapia es diferente**: no vendes un producto, vendes esperanza, sanación y transformación emocional. Cada palabra debe irradiar empatía, profesionalismo y confianza.

---

## 🎯 PRINCIPIOS FUNDAMENTALES

### 1. **Empatía sin sentimentalismo**

```
❌ Evitar: "Estás deprimido/a y sufres todos los días"
✅ Usar: "Si sientes que la vida ha perdido color, aquí hay luz."
```

Explicación: El primero es invasivo y alarmante. El segundo reconoce el dolor pero ofrece esperanza.

### 2. **Beneficio, no característica**

```
❌ "Sesiones de 50 minutos"
✅ "50 minutos enfocados completamente en ti, sin prisas"
```

### 3. **Transparencia + Calidez**

```
❌ "No garantizamos resultados"
✅ "No prometo milagros, pero sí prometo esfuerzo, profesionalismo y que trabajaremos juntos."
```

### 4. **Evitar jerga clínica con el público general**

```
❌ "Terapia cognitivo-conductual con enfoque humanista"
✅ "Combino técnicas probadas científicamente con un enfoque completamente humano"
```

### 5. **Llamada a la acción aspiracional**

```
❌ "Completa el formulario"
✅ "Empieza tu camino hacia el equilibrio emocional"
```

## 🗣️ MICROCOPY POR SECCIÓN

### HERO SECTION

**Titular Principal:**

```
"Tu bienestar emocional es mi prioridad"
```

**Por qué funciona:**

- Personalizado ("Tu")
- Emocional (no mental/psicológico)
- Directo y claro

**Alternativas para A/B testing:**

```
"Recupera tu paz mental en pocas sesiones"
"La terapia que te transforma desde adentro"
"Empieza a sentirte mejor hoy mismo"
"Tu salud emocional merecla atención profesional"
```

**Subtítulo:**

```
"Terapia psicológica profesional, empática y sin juzgamientos. Empieza tu camino hacia la paz mental con tu primera sesión gratuita"
```

**Elemento importante:** "sin juzgamientos"

- Esto reduce una barrera emocional enorme
- Muchas personas evitan terapia por "vergüenza"

---

### BOTONES / CTA

#### CTA PRINCIPAL (Hero)

```
"Solicita tu sesión gratuita"
```

Desglose de palabras:

- **Solicita** = acción clara, empoderadora
- **tu** = personalizado
- **sesión gratuita** = barrera de precio eliminada

**Alternativas:**

- "Empieza hoy a sentirte mejor"
- "Reserva tu primera sesión sin costo"
- "Cura tu ansiedad - primera sesión gratis"
- "Quiero vivir mejor - reservar ahora"

---

#### CTA SECUNDARIA

```
"¿Cómo funciona?"
```

**Por qué funciona:**

- Abordarás la objeción "no sé qué esperar"
- Menor compromiso que CTA principal
- Lleva a sección de "Cómo funcionan nuestras sesiones"

---

### SECTION: SOBRE TERAPIA

**Título:**

```
"¿Qué es la terapia psicológica y por qué es importante?"
```

**Párrafo de apertura:**

```
"La terapia psicológica es un espacio seguro, confidencial y profesional donde puedes explorar tus emociones, pensamientos y comportamientos. No se trata de 'estar loco/a' ni es algo vergonzoso: es un acto de amor y responsabilidad contigo mismo."
```

**Elementos clave aquí:**

- "espacio seguro" = elimina miedo
- "confidencial" = reafirma privacidad
- Normaliza la terapia = quita estigma
- "es un acto de amor contigo mismo" = empoderamiento

---

### SECTION: BENEFICIOS

```
✓ "Resultados reales: Aprenderás a manejar estrés y ansiedad con técnicas comprobadas"

✓ "Autoconocimiento: Entenderás mejor tus patrones emocionales y actuarás desde la consciencia"

✓ "Relaciones más saludables: Mejora cómo te relacionas con los demás"

✓ "Empoderamiento: Tendrás herramientas para enfrentar desafíos futuros"
```

**Por qué cada uno:**

1. **Resultados reales** = aborda "¿esto funciona?"
2. **Autoconocimiento** = posibilita el cambio duradero
3. **Relaciones** = beneficio secundario importante
4. **Empoderamiento** = no dependencia de terapeuta (saludable)

---

### SECTION: SESIONES

#### Online

```
"Desde la comodidad de tu hogar, con máxima privacidad. Utilizamos una plataforma segura y encriptada. Perfecta si tienes poco tiempo o vives en otra ciudad."
```

**Palabras clave:**

- "comodidad de tu hogar" = elimina fricción
- "máxima privacidad" = importante para vergüenza
- "segura y encriptada" = reafirma confidencialidad
- "si tienes poco tiempo" = resuelve barrera común

---

#### Presencial

```
"En un ambiente tranquilo y profesional, diseñado para tu comodidad. Ideal si prefieres el contacto directo y una experiencia más personal."
```

**Palabras clave:**

- "tranquilo" = anti-estrés
- "diseñado para tu comodidad" = personalizado
- "contacto directo" = conexión humana

### TESTIMONIOS

**Estructura ganadora:**

```
[Emoji Estrella] "Mi resultado específico"
"Mi historia en 2-3 frases, emocional pero creíble"
- Nombre, Condición
```

**Ejemplo:**

```
★★★★★
"Llevaba años con ansiedad sin saber cómo manejarla. Las sesiones me dieron herramientas reales que uso cada día. Me siento más tranquilo y en control de mis emociones."
- Marcos C., Ansiedad y estrés laboral
```

**Elementos que funcionan:**

- **"años con ansiedad"** = normaliza los problemas
- **"sin saber cómo"** = relatable
- **"herramientas reales"** = tangible, no vago
- **"uso cada día"** = resultado práctico
- **"tranquilo y en control"** = transformación clara

**Para tus propios testimonios, pide a clientes:**

> "¿Como te sentías ANTES de la terapia?"
> "¿Qué cambió después?"
> "¿Qué herramientas/técnicas fue lo más útil?"
> "¿Lo recomendarías? ¿Por qué?"

### FAQ - PREGUNTAS Y RESPUESTAS

#### P: "¿Cómo funciona una sesión de terapia?"

**Respuesta:**

```
"Una sesión típica dura 50 minutos. Empezamos creando un espacio seguro donde puedas expresarte libremente. Exploraré tu situación, escucharé activamente sin juzgar, y juntos trabajaremos en estrategias y soluciones personalizadas. El proceso es colaborativo: tú tienes la experiencia vivida, yo tengo las herramientas profesionales."
```

**Elementos clave:**

- **"espacio seguro"** = reduce ansiedad
- **"expresarte libremente"** = permiso emocional
- **"sin juzgar"** = crítico
- **"juntos"** = no es el terapeuta quien arregla, es colaboración
- **"tú tienes la experiencia"** = valida al cliente

---

#### P: "Es confidencial lo que hablo en terapia?"

**Respuesta:**

```
"Sí, 100%. El secreto profesional es un principio fundamental en psicología. Todo lo que compartas conmigo está protegido legalmente. Las únicas excepciones son situaciones de riesgo inminente (riesgo de daño a ti mismo o a otros), como requiere la ley. Tu privacidad es sagrada."
```

**Elementos clave:**

- **"Sí, 100%"** = respuesta clara e inmediata
- **"protegido legalmente"** = reafirma seriedad
- **"Las únicas excepciones son..."** = transparencia, no sorpresas
- **"Tu privacidad es sagrada"** = cálida, respetuosa

---

#### P: "¿Tengo que dejar la medicación si voy a terapia?"

**Respuesta(aquí es MUY importante la claridad):**

```
"No. Yo soy psicóloga, no psiquiatra. Si estás bajo medicación, es importante que continúes con tu médico. La terapia psicológica y la medicación pueden trabajar juntas de manera complementaria. Si tu médico prescribió medicamentos, él es quién decide si es necesario continuar o ajustar. Nosotros trabajamos en coordinación con tu equipo médico para tu máximo beneficio."
```

**Elementos clave:**

- **Aclaración de rol** = evita mal entendidos
- **Refuerza continuidad médica** = responsable
- **"complementaria"** = no competencia, sinergia
- **"en coordinación con tu equipo"** = profesionalismo

### FORMULARIO - MICROCOPY

#### Etiquetas

```
Nombre completo *
Placeholder: "Tu nombre"
Hint: (opcional) "¿Cómo prefieres que te llame?"

Correo electrónico *
Placeholder: "tu@correo.com"
Hint: "Te contactaré por aquí dentro de 24 horas"

Teléfono (opcional)
Placeholder: "+34 XXX XXX XXX"
Hint: "Si lo prefieres, también puedo llamar para coordinar"

¿Qué te trae aquí? *
Default: "-- Selecciona una opción --"
Opciones:
  • Ansiedad
  • Estrés
  • Depresión
  • Dificultades en relaciones
  • Baja autoestima
  • Estrés laboral
  • Duelo y pérdidas
  • Otro / Prefiero contar en la sesión ← IMPORTANTE

¿Qué modalidad prefieres? *
Default: "-- Selecciona una opción --"
Opciones:
  • Online
  • Presencial
  • Sin importar (Flexible) ← ESTO AUMENTA CONVERSIÓN
```

**¿Por qué "Flexible"?**

- Reduce objeciones
- Muestra adaptabilidad
- Cliente no se siente limitado

#### Textarea

```
Cuéntame brevemente tu situación (opcional)
Placeholder: "Comparte lo que te parezca relevante. Esto me ayudará a preparar mejor tu primera sesión."
```

**Elementos:**

- **"(opcional)"** = no presiona
- **"brevemente"** = no pide ensayo
- **"comparte lo que te parezca"** = control al usuario
- **"Esto me ayudará"** = beneficio mutuo

---

#### Checkbox de Privacidad

```
☐ He leído y acepto la política de privacidad *
```

**Versión más cálida (para mejorar conversión):**

```
☐ He leído y acepto la política de privacidad.
  Mi información será tratada con confidencialidad total. *
```

---

#### Botón Envío

```
Texto: "Solicita tu sesión gratuita"
```

**Estados diferentes:**

- **Normal**: "Solicita tu sesión gratuita"
- **Hover**: Cambio color + algo más pequeño hacia arriba (animación)
- **Activo/Presionado**: Color más oscuro
- **Enviado**: "¡Perfecto! Recibirás una respuesta en máximo 24 horas. Gracias por confiar en mí."

---

### CTA FINAL (antes de footer)

```
Titular:
"Tu bienestar mental es importante"

Subtítulo:
"No esperes más para sentirte mejor. Toma el primer paso hoy mismo."

Botón:
"Reserva ahora tu sesión gratuita"
```

**Elemento importante:** Cambio de lenguaje

- Primera vez: "Solicita" = pedido
- Segunda vez: "Reserva" = confirmación de que algo ya pasó
- Esto crea sensación de progreso

## 🎯 ESTRATEGIA DE PALABRAS CLAVE EN COPYWRITING

### High Conversion Intent Keywords

```
"sesión gratuita"      → Usa en hero + botones (4x)
"primera sesión"       → Usa en secciones explicativas (3x)
"sin compromiso"       → Muy poderoso, añadir donde sea posible
"online"               → Importante para público moderno (2x)
"ansiedad"             → Condición más buscada (2x)
"estrés"               → Muy relevante (2x)
```

### Dónde ubicarlas naturalmente

```
H1 ................. "Cura tu ansiedad" / "Terapia online"
H2 ................. "Beneficios" / "Cómo funciona online"
Párrafos iniciales .. "sesión gratuita", "sin compromiso"
CTA ................ "Solicita tu sesión gratuita"
FAQ ................ "¿Cuántas sesiones necesito?"
```

## 💬 EJEMPLOS DE MICROCOPY POR CONTEXTO

### Cuando el usuario DUDA

```
Botón alternativo / Enlace:
"¿Tienes preguntas? Lee las FAQ" ← Reduce fricción
"¿No estás seguro? Mira qué dicen otros" ← Social proof
```

### Cuando el usuario TEME

```
Cerca de CTA:
"Máxima confidencialidad garantizada"
"Sin compromiso. Solo una conversación inicial"
"Puedes cancelar cuando quieras"
```

### Cuando el usuario DUDA DEL PRECIO

```
"Inversión asequible en tu salud mental"
"Paquetes flexibles según tu presupuesto"
(No mostrar precio en landing, negociar en sesión gratuita)
```

### Cuando el usuario PROCRASTINA

```
CTA urgencia (suave, no agresiva):
"Empieza hoy"
"Tu bienestar no espera"
"El mejor momento era hace un año. El segundo mejor es ahora."
```

## 🎤 TONE OF VOICE

### El tono debe ser:

✅ **Empático** - Entiendo tu dolor  
✅ **Profesional** - Sé lo que hago  
✅ **Accesible** - Puedo hablar con alguien como tú  
✅ **Esperanzador** - Hay salida  
✅ **Honesto** - Te digo la verdad  
✅ **Cálido** - Te importo como persona

### NO debe ser:

❌ Clínico o pedante  
❌ Alarmista o catastrofista  
❌ Exagerado o sensacionalista  
❌ Frío o robótico  
❌ Demasiado casual o poco profesional  
❌ Manipulador o invasivo

## 📱 MICROCOPY PARA MÓVIL

En móvil, el espacio es limitado. Adapta:

```
Desktop: "Solicita tu sesión gratuita ahora"
Móvil:   "Sesión gratuita"

Desktop: "Completa el formulario de contacto"
Móvil:   "Contáctame"

Desktop: "Reserva tu cita desde cualquier lugar"
Móvil:   "Reserva tu cita"
```

- Debe empoderar al cliente

- Debe mantener la humanidad

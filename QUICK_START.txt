1. VAL A: https://netlify.com
2. CLICK: "Sign up with GitHub" (crea cuenta GitHub si no tienes)
3. EN GITHUB:

   ├─ Crea cuenta nuevo repo
   ├─ Nombre: "psicóloga-web" o lo que quieras

   ├─ Click: "New site from git"
   ├─ Selecciona tu repo
   ├─ Espera a que se publique (~1 minuto)

================================================================================

1. VE A: https://namecheap.com
2. BUSCA dominio (ej: psicologacano.com )
3. COMPRA (~$9/año)
4. EN NETLIFY:
   ├─ Tu sitio → Domain settings
   ├─ Add custom domain
   ├─ Ingresa tu dominio nuevo
   ├─ Copia nameservers
5. EN NAMECHEAP:
   ├─ Domain → Nameservers
   ├─ Pega nameservers de Netlify
   └─ Espera 24-48 horas (propagación DNS)

================================================================================
  🆘 PROBLEMAS COMUNES
================================================================================

P: El formulario no envía emails
R: 1. Verificar que hayas reemplazado YOUR_FORMSPREE_ID correctamente
   2. Revisar consola de navegador (F12)
   3. Ver FAQ_DESARROLLADORES.md

P: No se ven cambios en CSS
R: Abre DevTools (F12) y haz Ctrl+Shift+R para vaciar caché

P: JavaScript no funciona
R: 1. Verifica que el archivo script.js exista en assets/js/
   2. Abre consola (F12) y busca errores rojos

P: Sitio lento en móvil
R: 1. Comprime imágenes (tinypng.com)
   2. Minifica CSS/JS
   3. Lee GUIA_DISENO_Y_PERSONALIZACION.md
